# スマホまるごと診断（PlanFit）

① 料金プラン診断 ② スマホ安全診断 ③ スマホ契約診断 の3つをタブで切り替えて使えます。
URLの末尾に `#plan` `#safety` `#contract` を付けると、そのタブを直接開けます。

## ファイル構成

- index.html：画面（HTML / CSS）
- app.js：画面の動き（結果の描画・共有URL・相談メモ・入力の保存）
- diagnosis.js：①料金プラン診断のロジック（DOMに依存しない純粋関数）
- checks.js：②スマホ安全診断・③スマホ契約診断の質問データと判定ロジック
- plans.js：料金プランデータ（ブランドごとに複数プラン・通話オプション料金つき）と、月額推定用の典型料金
- version.js：バージョンと確認日
- tests/：診断ロジックのテスト（`node --test tests/*.test.js`）

- スマホでスタッフ用の帯を1行にまとめた
- 一般モードは従来どおり店舗への相談導線を表示

## v3.2 で追加

- ② スマホ安全診断：OS更新・画面ロック・不審なアプリ・権限・詐欺被害・パスワード・2段階認証など12問。点数と、iPhone／Android別の直し方を表示。詐欺被害の可能性があれば至急対応（188・#9110）を表示

## v3.0 の主な機能

- ブランドごとに複数のデータ容量プランから、使い方に合うものを選ぶ
- 通話の使い方に応じて、かけ放題オプション代を上乗せして実質月額を比較
- 「今の月額がわからない」場合は、ブランドと使い方から推定
- 同じブランドならプラン変更で済む（乗り換え不要）と表示
- おすすめは1ブランド1枠で上位3つ。料金だけで見た最安プランも別に表示
- 今より安いプランがなければ「今のままでOK」と表示
- 結果を共有できるURL・LINE送信。前回の入力を自動で復元
- お困りごとのチェックから、窓口に見せられる「相談メモ」を作成

## 料金の自動チェック

毎月1日に Claude Code が各社の公式サイトで料金を確認し、変更があれば `plans.js` を直したPRを作ります（`price-check/YYYY-MM` ブランチ）。
公式サイトが自動アクセスを拒否するブランド（LINEMO・Y!mobile など）は、PRに「手動確認が必要」と書かれるので、ブラウザで確認してください。
PRの内容を確認してマージすれば、Vercel に反映されます。

## 料金更新の手順（手動）

1. 各キャリアの公式料金ページを確認
2. plans.jsを開く
3. price、data、name、callIncluded、callOptionsを変更（プランの追加・削除も可）
4. checkedAtを更新
5. version.jsのversionとpriceCheckedAtを更新
6. `node --test tests/*.test.js` でテストが通るか確認
7. Vercelのプレビューを確認
8. 問題がなければ本番公開
