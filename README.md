# あなたに合う料金プラン診断

## ファイル構成

- index.html：画面と診断機能
- plans.js：料金プランデータ
- version.js：バージョンと確認日

## 料金更新の手順

1. 各キャリアの公式料金ページを確認
2. plans.jsを開く
3. price、data、nameを変更
4. checkedAtを更新
5. version.jsのversionとpriceCheckedAtを更新
6. Vercelのプレビューを確認
7. 問題がなければ本番公開
